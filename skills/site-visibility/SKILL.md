# Site visibility

Use the Cool Web Tool connector after the user signs in with their own Cool Web Tool account.

1. When the user gives a site URL and has no recent audit, run a site audit.
2. Read AI visibility, competitor gaps, and the pages to fix from that account.
3. When a result names pages, list those URLs. When a tool reports that no audit or no AI visibility scan exists, say that.
4. Do not invent scores, citation share, traffic, or keyword volumes.
